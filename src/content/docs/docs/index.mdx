magicui-solid is a port of [Magic UI](https://magicui.design) components for [SolidJS](https://solidjs.com).

It provides beautifully designed, animated UI components that you can copy, paste, and customize into your SolidJS projects.

## Philosophy

Great design builds trust. The same care we put into animations and interactions reflects the quality your users can expect from your product.

magicui-solid brings that same attention to detail to the SolidJS ecosystem, letting you create polished user experiences without starting from scratch.

This library is heavily inspired by [Magic UI](https://magicui.design) and [shadcn/ui](https://ui.shadcn.com).
