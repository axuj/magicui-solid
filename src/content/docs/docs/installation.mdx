magicui-solid components are distributed via the shadcn registry and can be installed using the shadcn CLI.

## Prerequisites

- A SolidJS project with [Tailwind CSS v4](https://tailwindcss.com) configured
- [Node.js](https://nodejs.org) 18+

## Add the Registry

Add the `@magicui-solid` registry to your project's `components.json`:

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "default",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "src/app.css",
    "baseColor": "neutral",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "iconLibrary": "lucide",
  "registries": {
    "@magicui-solid": "https://magicui-solid.vercel.app/r/{name}.json"
  }
}
```

Or use the CLI to add the registry:

## Install a Component

Now you can install any component from the registry:

<PackageManagerTabs>
  <Fragment slot="npm">
    ```bash
    npx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="pnpm">
    ```bash
    pnpm dlx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="yarn">
    ```bash
    yarn dlx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="bun">
    ```bash
    bunx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
</PackageManagerTabs>

The component and its dependencies will be installed into your project.

## Manual Installation

Alternatively, you can copy the component source directly from the [GitHub repository](https://github.com/axuj/magicui-solid).

You'll also need to install the required dependencies:

```bash
npm install @solid-primitives/intersection-observer clsx tailwind-merge
```
