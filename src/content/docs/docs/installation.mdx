magicui-solid components are distributed via the shadcn registry and can be installed using the shadcn CLI.

## Prerequisites

- A **Solid 2** project. This registry is built against `solid-js@2.0.0-rc.21` / `@solidjs/web@2.0.0-rc.21`; Solid 1 projects are not supported.
- [Tailwind CSS v4](https://tailwindcss.com) configured
- [Node.js](https://nodejs.org) 18+
- Components that use Kobalte pin `@kobalte/core@2.0.0-alpha.4`; the CLI installs it automatically.
- npm users need `legacy-peer-deps=true` in the project's `.npmrc`: Kobalte 2 alpha still declares `solid-js` / `@solidjs/web` peers at `2.0.0-rc.16`, while this registry targets `rc.21`. Without it, `npm install` fails with `ERESOLVE`.

## Add the Registry

Add the `@magicui-solid` registry to your project's `components.json`:

```json
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "default",
  "rsc": false,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "src/app.css",
    "baseColor": "neutral",
    "cssVariables": true,
    "prefix": ""
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  },
  "iconLibrary": "lucide",
  "registries": {
    "@magicui-solid": "https://axuj.github.io/magicui-solid/v2/r/{name}.json"
  }
}
```

Or use the CLI to add the registry:

## Install a Component

SolidJS projects can't use `shadcn init` (it's designed for React). Instead, the base theme is distributed as a registry item (`@magicui-solid/theme`) and installed automatically as a dependency when you add any component:

<PackageManagerTabs>
  <Fragment slot="npm">
    ```bash
    npx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="pnpm">
    ```bash
    pnpm dlx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="yarn">
    ```bash
    yarn dlx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
  <Fragment slot="bun">
    ```bash
    bunx shadcn@latest add @magicui-solid/terminal
    ```
  </Fragment>
</PackageManagerTabs>

That's it. The CLI installs the component, its dependencies, and automatically injects the entire theme into your `app.css`: all CSS variables (`:root`/`.dark`), Tailwind v4 color mappings (`@theme inline`), radius scale, and animation keyframes (e.g. `animate-marquee`). No manual configuration required.

> **Note:** If your `app.css` already contains shadcn variables, the CLI keeps your existing values and only appends what's missing.

## Manual Installation

Alternatively, you can copy the component source directly from the [GitHub repository](https://github.com/axuj/magicui-solid).

You'll also need to install the required dependencies and add the theme manually:

```bash
npm install @solid-primitives/intersection-observer clsx tailwind-merge
```
