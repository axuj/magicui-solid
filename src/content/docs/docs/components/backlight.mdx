## Usage

```tsx showLineNumbers

```

```tsx showLineNumbers
<Backlight>
  <img src="https://some-url/image.png" />
</Backlight>
```

## Props

| Prop       | Type          | Default | Description                                                        |
| ---------- | ------------- | ------- | ------------------------------------------------------------------ |
| `blur`     | `number`      | `20`    | The blur intensity of the backlight glow effect.                   |
| `children` | `JSX.Element` | `-`     | The video, image, or SVG element to apply the backlight effect to. |
| `class`    | `string`      | `-`     | Additional class names for the wrapper div.                        |
