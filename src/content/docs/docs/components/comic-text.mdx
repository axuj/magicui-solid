## Usage

```tsx
import { ComicText } from "@/components/magicui/comic-text"
```

```tsx
<ComicText>Comic Text</ComicText>
```

## Props

| Prop       | Type            | Default | Description                                   |
| ---------- | --------------- | ------- | --------------------------------------------- |
| `class`    | `string`        | `-`     | The class name to be applied to the component |
| `fontSize` | `number`        | `5`     | The font size of the text                     |
| `style`    | `CSSProperties` | `-`     | The style of the text                         |
| `children` | `string`        | `-`     | The text to be displayed                      |
