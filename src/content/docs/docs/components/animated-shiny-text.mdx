## Import

```tsx
import { AnimatedShinyText } from '@/components/magicui/animated-shiny-text'
```

## Usage

```tsx
<AnimatedShinyText>Hello</AnimatedShinyText>
```

## Props

| Prop           | Type          | Default | Description                                  |
| -------------- | ------------- | ------- | -------------------------------------------- |
| `children`     | `JSX.Element` | `-`     | The text to be shimmered.                    |
| `class`        | `string`      | `-`     | The class name to be applied to the shimmer. |
| `shimmerWidth` | `number`      | `100`   | The width of the shimmer in pixels.          |
