## Props

### StripedPattern

| Prop        | Type               | Default  | Description                        |
| ----------- | ------------------ | -------- | ---------------------------------- |
| `width`     | `number`           | `10`     | Width of the pattern               |
| `height`    | `number`           | `10`     | Height of the pattern              |
| `direction` | `"left"` `"right"` | `"left"` | Line direction                     |
| `class`     | `string`           | `-`      | Additional classes on the root SVG |
