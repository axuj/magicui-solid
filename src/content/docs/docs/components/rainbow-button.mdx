## Props

| Prop       | Type                               | Default     | Description                                         |
| ---------- | ---------------------------------- | ----------- | --------------------------------------------------- |
| `class`    | `string`                           | `-`         | Additional CSS classes to be applied to the button. |
| `children` | `JSX.Element`                      | `-`         | The content to be displayed inside the button.      |
| `as`       | `ValidComponent`                   | `"button"`  | The element or component to render as.              |
| `variant`  | `"default"` `"outline"`            | `"default"` | The variant of the button.                          |
| `size`     | `"default"` `"sm"` `"lg"` `"icon"` | `"default"` | The size of the button.                             |
