## Props

| Prop          | Type                                                         | Default          | Description                                                         |
| ------------- | ------------------------------------------------------------ | ---------------- | ------------------------------------------------------------------- |
| `class`       | `string`                                                     | `-`              | Additional CSS classes for the root element.                        |
| `pattern`     | `"horizon"` / `"glow"` / `"aurora"` / `"waves"` / `"clouds"` | `"horizon"`      | The procedural light field that the dots follow.                    |
| `src`         | `string`                                                     | `-`              | Image or video URL to dither instead. Remote files must allow CORS. |
| `color`       | `string` / `string[]`                                        | `"currentColor"` | A CSS color, or a `[low, mid, high]` ramp from dim to bright dots.  |
| `dotSize`     | `number`                                                     | `1`              | Size of one dot in CSS pixels.                                      |
| `intensity`   | `number`                                                     | `0.75`           | Brightness of the field.                                            |
| `speed`       | `number`                                                     | `1`              | Animation speed. `0` holds a still frame.                           |
| `fps`         | `number`                                                     | `30`             | Maximum frames per second.                                          |
| `interactive` | `boolean`                                                    | `true`           | Brighten the dots under the pointer.                                |
