## Import

```tsx
import { InteractiveHoverButton } from '@/components/magicui/interactive-hover-button'
```

## Usage

```tsx

```

| Prop       | Type          | Default | Description                                   |

| `class`    | `string`      | `-`     | Additional class names to style the component |
