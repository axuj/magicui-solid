## Import

```tsx
import { AnimatedList, AnimatedListItem } from '@/components/ui/animated-list'
```

## Usage

```tsx
<AnimatedList delay={1500}>
  <AnimatedListItem>
    <p>Item 1</p>
  </AnimatedListItem>
  <AnimatedListItem>
    <p>Item 2</p>
  </AnimatedListItem>
  <AnimatedListItem>
    <p>Item 3</p>
  </AnimatedListItem>
</AnimatedList>
```

## Props

### AnimatedList

| Prop       | Type          | Default | Description                       |
| ---------- | ------------- | ------- | --------------------------------- |
| `class`    | `string`      | `-`     | Optional CSS class name.          |
| `delay`    | `number`      | `1000`  | The delay between each item in ms |
| `children` | `JSX.Element` | `-`     | The items to animate.             |
